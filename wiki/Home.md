## 🚀 Project Overview

**Streamify** is an AI-native OTT movie discovery platform that leverages:
- **Vector Database (Pinecone)** for semantic search
- **OpenAI Embeddings** for content understanding
- **FastAPI** for high-performance backend
- **React** for modern frontend
- **PostgreSQL** for relational data

## 🎯 Key Features

- 🔍 **Semantic Search** - Natural language movie discovery
- 🤖 **AI Recommendations** - Personalized suggestions using vector similarity
- 📝 **Watchlist Management** - Track movies to watch
- 🔐 **Secure Authentication** - JWT-based auth system
- 📊 **User Profiles** - Personalized user preferences
- 🎬 **Rich Movie Data** - Comprehensive movie metadata

## 🛠️ Tech Stack

### Backend
- FastAPI (Python 3.11+)
- PostgreSQL (Database)
- Pinecone (Vector Database)
- OpenAI API (Embeddings)
- SQLAlchemy (ORM)
- Alembic (Migrations)

### Frontend
- React 18
- TypeScript
- Tailwind CSS
- React Query
- React Router
